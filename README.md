# Бүртгэлийн веб

Овог, нэр, Монгол утасны дугаар, имэйлийг SQLite-ийн `Register.db` өгөгдлийн санд хадгална.
Нууц үгээр нэвтэрсэн админ `/admin` хуудаснаас бүртгэлүүдийг харж, Excel файл татаж авна.

## Ажиллуулах

1. Python 3.9 буюу түүнээс шинэ хувилбар суулгасан байна.
2. Терминал нээгээд төслийн хавтас руу орно.
3. Сангуудыг суулгана:

   ```bash
   python3 -m pip install -r requirements.txt
   ```

4. Админы нууц үг болон Flask session-ийн нууцыг тохируулна. Нууц үгт өөрийн сонгосон
   утгыг ашиглаж, кодонд шууд хадгалахгүй:

   ```bash
   export ADMIN_PASSWORD='өөрийн-урт-админы-нууц-үг'
   export SECRET_KEY="$(python3 -c 'import secrets; print(secrets.token_hex(32))')"
   ```

   `SECRET_KEY`-г дахин эхлүүлэх бүрдээ сольж болохгүй. Нууц үг болон түлхүүрийг
   бусдад дамжуулахгүй. Тохируулаагүй бол админ хэсэгт нэвтрэх боломжгүй.

5. Вебийг ажиллуулна:

   ```bash
   python3 app.py
   ```

6. Бүртгэлийн нүүрийг `http://127.0.0.1:5000`, админы хуудсыг
   `http://127.0.0.1:5000/admin` хаягаар нээнэ.

Утасны дугаарыг 8 оронтой, имэйлийг `ner@example.com` жишээний дагуу оруулна.
`Register.db` файл төслийн хавтаст автоматаар үүснэ. Өгөгдлийг нөөцлөхдөө веб аппыг
зогсоогоод уг файлыг хуулна. Хэрэв өмнөх `Register.xlsx` байвал эхний ажиллуулах үед
бүртгэлүүдийг SQLite рүү нэг удаа импортолж, эх файлыг өөрчлөхгүй үлдээнэ. Цаашдын
бүртгэл SQLite-д хадгалагдана. Бодит серверт HTTPS ашиглаж, debug горимыг идэвхжүүлэхгүй байна.
